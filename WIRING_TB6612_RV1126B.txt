================================================================================
RV1126B 开发板  <-->  TB6612(D153B) 双路电机驱动模块   接线说明
版本：v1.1.0        整理日期：2026-09-14
================================================================================

本文件说明如何把 ELF-RV1126B 开发板（板端排针）连接到轮趣 TB6612 双路驱动模块
（WHEELTEC D153B，带 5V/3V3 稳压），用于驱动 2 台 MG310 霍尔编码器减速电机。
TB6612 模块由外部 12V 电源直接供电，RV1126B 只提供 3.3V 控制信号。

配套文件：
  MOTOR_MG310_TB6612_RV1126B.md     例程整理 / 线序 / 引脚依据
  MOTOR_SYSTEM_DESIGN_RV1126B.md    系统设计方案（12 章）
  motor_ctl.py                      电机控制守护进程（引脚定义见文件头部 CFG）
  motor_web.py                      HTTP 控制网桥（:8081，网页面板后端）
  motor-ctl.service / motor-web.service   systemd 服务


--------------------------------------------------------------------------------
一、总体连接拓扑
--------------------------------------------------------------------------------

       12V/3A 适配器
            |
            +----------------> D153B 模块  VM / VIN+（电机功率）
            |                        |
            |                        +-- 6PIN 排线 --> MG310 电机 A / B（含编码器）
            |                        +-- 3V3 / 5V / GND --> 编码器供电
            |
            +--（可选）12V->5V DC-DC --> RV1126B DC_5V

   5V/2A 适配器 ----------------------------> RV1126B DC_5V（推荐独立供电）

   RV1126B  -- PWM x2 + 方向 GPIO x4 --> D153B Input_IO
   RV1126B  <-- 编码器 A/B 相 x4 ------ D153B Output_IO
   RV1126B  <-- GND -------------------------------- D153B GND1（必须共地）


--------------------------------------------------------------------------------
二、引脚对应关系（重点）
--------------------------------------------------------------------------------

1) 控制信号（D153B Input_IO 7pin 排针 H1  ->  RV1126B 排针）

  D153B 引脚 | 信号含义        | RV1126B 引脚 | GPIO 编号 | 说明
  -----------+-----------------+--------------+-----------+------------------------
  PWMA       | A 路 PWM 调速   | GPIO5_C0     | 176       | PWM3_CH0，10kHz
  AIN1       | A 路方向 1      | GPIO5_C2     | 178       | 普通 GPIO 输出
  AIN2       | A 路方向 2      | GPIO5_C3     | 179       | 普通 GPIO 输出
  PWMB       | B 路 PWM 调速   | GPIO5_C1     | 177       | PWM3_CH1，10kHz
  BIN1       | B 路方向 1      | GPIO5_C4     | 180       | 普通 GPIO 输出
  BIN2       | B 路方向 2      | GPIO5_C5     | 181       | 普通 GPIO 输出
  STBY       | 驱动芯片使能    | ——           | ——        | 直接接模块 3V3（常使能）

2) 编码器反馈（D153B Output_IO 7pin 排针 H2  ->  RV1126B 排针）

  D153B 引脚 | 信号含义        | RV1126B 引脚 | GPIO 编号 | 说明
  -----------+-----------------+--------------+-----------+------------------------
  E1A        | A 电机编码器 A 相 | GPIO5_C6   | 182       | 输入（边沿中断）
  E1B        | A 电机编码器 B 相 | GPIO5_C7   | 183       | 输入（边沿中断）
  E2A        | B 电机编码器 A 相 | GPIO5_D0   | 184       | 输入（边沿中断）
  E2B        | B 电机编码器 B 相 | GPIO5_D1   | 185       | 输入（边沿中断）
  ADC        | 电源电压检测     | 不接（可选）| ——        | 1/11 分压，可接 SARADC
  5V / GND   | 输出            |             | ——        | 编码器供电 / 共地

3) 电源端子

  D153B 端子 | 接法                     | 说明
  -----------+--------------------------+-------------------------------------
  VM / VIN+  | 12V 适配器正极           | 电机功率电源，不得超过 13.5V
  GND2       | 12V 适配器负极           | 功率地
  GND1       | 与 RV1126B GND 相连      | 逻辑地，必须与开发板共地
  5V / 3V3   | 编码器供电（优先 3V3）   | 见第四节“电平匹配”

GPIO 编号换算：编号 = n x 32 + (组序号-1) x 8 + y
  组序号：A=1 B=2 C=3 D=4      例：GPIO5_C0 = 5x32 + 2x8 + 0 = 176
  （与 motor_ctl.py 中 CFG 的 pwm/in1/in2/ea/eb 字段一一对应，可按需修改）


--------------------------------------------------------------------------------
三、连接步骤
--------------------------------------------------------------------------------

步骤 1：电机接到驱动模块（6PIN 排线直接插，无需改线）
  Motor_A 接口：1=GND  2=AOUT1  3=E1A  4=E1B  5=AOUT2  6=5V
  Motor_B 接口：1=GND  2=BOUT1  3=E2A  4=E2B  5=BOUT2  6=5V
  MG310 电机侧线序（供核对）：
    1 电机线-（棕） 2 编码器电源（红） 3 A 相（绿） 4 B 相（白）
    5 编码器地（黑） 6 电机线+（黄）
  注：A/B 相颜色在不同批次资料中标注可能互换；接反只会导致计数方向相反，
      在 motor_ctl.py 的 CFG 中把该电机的 enc_inv 取反即可，无需改线。

步骤 2：12V 电源接驱动模块
  12V+ -> VM/VIN+，12V- -> GND2；建议在 VM 端保留模块自带 220uF 储能电容。
  开发板用独立 5V/2A 适配器接 DC_5V，不要与电机共用细线（避免启动时压降复位）。

步骤 3：共地
  用一根杜邦线把 D153B 的 GND1 与 RV1126B 排针 GND 相连（功率地与逻辑地单点汇合）。

步骤 4：接控制信号（7 根）
  PWMA->176  AIN1->178  AIN2->179  PWMB->177  BIN1->180  BIN2->181  GND->GND
  并把模块 STBY 引脚接到模块自身 3V3 输出（常使能；软件侧无需控制）。

步骤 5：接编码器反馈（4 根 + 供电）
  E1A->182  E1B->183  E2A->184  E2B->185，编码器电源从模块 3V3 取（推荐），
  若从 5V 取电必须先做电平转换（见下节）。

步骤 6：上电与自检
  上电顺序：先 12V（驱动模块），后 5V（开发板）。
  断电顺序：先停止电机（PWM=0），再断 12V，最后断开发板电源。


--------------------------------------------------------------------------------
四、电平匹配与保护（务必阅读）
--------------------------------------------------------------------------------

* RV1126B 的 GPIO 为 3.3V 电平，绝不允许接入超过 3.3V 的信号。
* 方向：RV1126B -> TB6612 为 3.3V 输出到 5V 逻辑输入，TB6612 的 VIH 约 2.0V，
  3.3V 可直接识别，无需转换。
* 方向：TB6612 -> RV1126B（编码器 AB 相）输出高电平 = 编码器供电电压：
    - 编码器用模块 3V3 供电  -> AB 相高电平 3.3V，可直连 GPIO（推荐，零成本）
    - 编码器用模块 5V 供电   -> AB 相高电平约 5V，必须先分压（串 2kΩ + 对地 3.3kΩ，
                                约 3.1V）或用 TXS0108E / 74LVC245 电平转换，否则会烧 GPIO
* 保护建议：12V 输入端串 3A 自恢复保险丝（PTC）与防反接二极管；信号线串 100Ω；
  调试时先把电机架空，确认转向正确后再上机。


--------------------------------------------------------------------------------
五、软件侧对应与验证命令
--------------------------------------------------------------------------------

* 引脚定义位置：/userdata/rtc/motor_ctl.py 文件顶部 CFG 字典
    A: pwm=176 in1=178 in2=179 ea=182 eb=183
    B: pwm=177 in1=180 in2=181 ea=184 eb=185
  修改后执行：sudo systemctl restart motor-ctl

* 服务管理
    sudo systemctl enable --now motor-ctl     # 电机控制守护进程
    sudo systemctl enable --now motor-web     # HTTP 网桥（:8081）
    systemctl status motor-ctl motor-web

* 命令行验证（板端）
    sudo python3 /userdata/rtc/motor_ctl.py --cmd "A speed 300"   # A 路开环 30%
    sudo python3 /userdata/rtc/motor_ctl.py --cmd "A rpm 200"     # A 路闭环 200rpm
    sudo python3 /userdata/rtc/motor_ctl.py --cmd "A stop"        # 停止
    curl -s http://127.0.0.1:8081/api/status                      # 查看状态

* 网页控制（视频与电机联动）
    http://<板卡IP>:3000/Browser_client.html   观看端 + 电机面板
    http://<板卡IP>:3000/Dual_webrtc.html      双端页 + 电机面板
    面板每秒刷新状态：模式 / 占空比 / 实时转速（rpm）


--------------------------------------------------------------------------------
六、常见故障排查
--------------------------------------------------------------------------------

1) 电机不转：确认 STBY 已接 3V3；确认 PWM 有输出（开环 duty >= 60 才克服静摩擦）；
   确认 VM 有 12V 且 GND 已共地。
2) 转向相反：调换 AIN1/AIN2 接线，或在软件里把该电机的 inv 取反。
3) 转速显示为 0 或计数乱跳：检查编码器供电与 A/B 相接线；转动电机时用万用表测
   AB 相对地电压应在 0~VCC 之间摆动（约 1.6~1.8V 平均）。
4) 设速时电机一冲一停：多为编码器未接好或供电不足导致反馈丢失，
   或负载过重（可用开环测试排除）；检查 12V 适配器电流是否足够（建议 >= 3A）。
5) 双电机同时运行时转速上不去：两路共用 12V 电源，大电流下电源被拉垮，
   请加大适配器电流或双电源分别供电（仍需共地）。
6) 开发板重启/复位：多为电机启动时拉低共用电源导致，务必让开发板独立供电。
